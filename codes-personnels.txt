Codes personnels — Atelier passé composé
=========================================

Distribue UN code à chaque élève. L'élève entre son code au démarrage :
sa progression est sauvegardée et retrouvée quand il revient (sur le même
navigateur / appareil).

Dans ton Google Sheet, crée un onglet « Codes » avec les colonnes :
  Code personnel | Prénom | Nom | Groupe
Colle les 30 codes ci-dessous dans la colonne « Code personnel », puis
remplis Prénom / Nom / Groupe au fur et à mesure que tu les distribues.
Les résultats (onglet « Résultats ») afficheront automatiquement le
prénom et le nom correspondants au code.
